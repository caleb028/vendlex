# VendLex 🇰🇪

> **Kenyan Marketplace | Buy. Sell. Grow.**  
> *Kenya's Business Marketplace & Growth Platform*

VendLex is a premier African technology platform combining a multi-vendor marketplace, verified Kenyan business directory, digital storefronts, services marketplace, full-suite seller SaaS business management system, customer hub, AI business assistant, and Safaricom Daraja M-Pesa automated payment architecture.

---

## 🌟 Key Features

### 1. Unified Kenyan Commerce Ecosystem
- **Multi-vendor Marketplace**: Products & services across all 47 counties in Kenya with prices in **KSh (Kenyan Shillings)**.
- **Cinematic Kenyan Hero Slideshow**: Smooth crossfade, Ken Burns zoom, and multi-attribute search across products, stores, and services.
- **Verified Business Directory**: Physical locations, county filters, ratings, and instant WhatsApp/Call contact modals.
- **Kenyan Services Hub**: Book verified plumbers, electricians, solar contractors, photographers, and caterers.
- **5-Step Checkout with Safaricom Daraja M-Pesa STK Push**: Realistic Safaricom STK push simulation and live API routes with PIN prompts, countdowns, and printable receipts.

### 2. Seller SaaS Business Management Suite
- **Interactive KPI Dashboard**: Gross sales, order pipeline, store visits, and conversion rates.
- **Product & Inventory Management**: Low-stock threshold warnings, instant stock adjustment, and category organization.
- **Orders Pipeline**: Visual status progression (`Pending -> Confirmed -> Processing -> Ready -> Shipped -> Delivered`).
- **Customer CRM**: Buyer history, lifetime spend, and 1-click WhatsApp customer messaging.
- **KRA-Ready Invoicing Engine**: Automated tax invoice generation with 16% VAT, itemized tables, print and PDF download.
- **Promotions & Flash Deals**: Create coupon codes and time-limited discounts.
- **VendLex AI Assistant**: Bilingual Swahili/English AI generator for social media posts, SEO descriptions, and customer replies.

## 🚀 Getting Started

```bash
# Navigate to the project directory
cd C:\Users\ADMIN\.gemini\antigravity\scratch\sokolink

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
